# 已踩过的坑（每条一行：症状 → 解决办法）

## 渲染
- **GPU 着色器出现 NaN**：一个坏像素会被 mip 泛光放大成闪烁的黑方块。重着色器的输出都要加 `if(any(isnan(c))||any(isinf(c))) c=vec3(0.);`（`vk_gl` 的 resolve 已内置），每个分段都要跑 `vk_scan.py spikes`。
- **多重采样噪点每帧乱爬**：每帧使用相同的抖动序列（`vk_gl` 已这样做）。
- **重着色器在 Windows 上触发 GPU TDR 重置**：使用 `GL(tiles=4)` 分条渲染。
- **泛光把画面冲白**：`vk_core` 的泛光叠加了多级模糊，发光层亮度控制在约 0.3–0.6，大面积区域（太阳、天空）不要画进 `cv.g`，而是画在底层，发光层只用于闪光。
- **轮廓光用整条路径描边，内部边缘也发光**（像霓虹描边）：在发光层先描边，再用 OPERATOR_SOURCE 黑色填充路径内部。
- **俯视角色太小、太抽象**：在联系表里检查尺寸。1080p 下角色约 90 px 以上，轮廓要有辨识度。
- **镜头平移或缩放露出画布边缘**：保持 `W/2/zoom ≤ cx ≤ W − W/2/zoom`，或把背景画得比画面大。
- **慢动作、倒带等时间重映射**：倒带结束后的状态里，子弹这类瞬时物体不能再绘制，否则会冻结在画面上。
- **pycairo 的 `ImageSurface` 不能挂属性**：用模块级列表保持 numpy 缓冲区存活（`vk_core` 的 `_KEEP`）。
- **文字在 t=0 从透明度 0 淡入**：第 0 帧没有标题，用 `a0`。
- **切点的闪白让 3 帧以上全白**：峰值不超过 0.6，并快速衰减（`exp(-t*5)`）。
- **浅色字压在高亮的太阳上**：在高亮区域的标签后面加半透明底板。

## 性能与运维
- **16 GB 内存开 10 个进程会 MemoryError**：每个进程缓存 0.6–1 GB 纹理，最多开 5 个进程，GPU 渲染只开 1 个。
- **工作进程里 BLAS 线程过多**：设置 `OMP_NUM_THREADS=1`（`vk_render` 已设置）。
- **agent 的 shell 工具通常有超时**：长时间渲染放到后台，用 `tail` 轮询日志。
- **shell heredoc 里嵌套引号会破坏多文件写入**：用 agent 的文件写入工具创建文件。
- **分段渲染中途被杀或崩溃**：分段先写 `.tmp` 再改名，重跑会自动续渲；要强制重做就删掉对应分段。
- **1080p cairo 渲染速度**：每帧约 0.3–0.5 秒；177 秒、30 fps 的片子用 5 个进程约 20 分钟。

## 音频
- **不同长度的数组相加报广播错误**：用 `P(a, b, ...)`。
- **用户提供的 BGM 开头很长或很安静**：仍从 0 秒开始用（不要跳过前奏），但在第 0 帧放响亮音效；切点对齐 `vk_bgm` 找出的 HITS。
- **最终响度**：始终跑 `vk_finalize`（loudnorm −14 LUFS）。母带处理前的混音 RMS 可能只有约 −15 dB。
- **模拟里的咔哒声太密，变成白噪声**：增益按 1/√密度缩放（`click_rain` 已实现）。
- **第一秒没有声音**：在 t = 0 放一个轻的撞击声或低频轰鸣。
- **agent 无法试听**：如实告诉用户，改用每秒电平数据做检查。

## 内容
- **概率、物理结论**：在代码里精确推导（`fractions.Fraction`）并 `assert`；模拟用固定随机种子，报告模拟的实际数字，而不是理论值。
- **前提假设**：用小字写在画面上（如"假设三人都按最优策略行动"），否则观众会在评论里追问。
