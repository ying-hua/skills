# 惊艳标准：look-dev 时检查一次，交付前再检查一次

## 开场钩子（短视频平台尤其重要）
- **第 0 帧就是完整画面**：要有醒目的场景、可读的标题、正在进行的动作，t = 0 就有声音。
  - 不要黑屏，不要从黑场淡入，标题也不能从透明度 0 淡入。
  - 标题在第 0 帧就要几乎完全不透明（用"砸入"缩放代替透明度淡入），第 0 帧的闪白控制在 0.15 以内。
  - 第 0 帧要用数值检查，或放进 look-dev 联系表里确认。
- **2 秒内要有"事件"**：枪响、啪的一声、揭示或速度突变。
- **约 10 秒内**让观众知道悖论或问题是什么、令人惊讶的答案存在，但先不说为什么。
- 钩子里用全片最强的画面做预告，例如子弹时间后，只剩枪法最差的人站着。

## 招牌可视化（每个视频恰好一个，要精雕细琢）
- 必须是只有这个主题才会有、并且承担论证作用的可视化。例如流动颗粒的概率桑基图、实时求解器、收敛到理论刻度的万次模拟网格。
- 结论展示两次：一次推导（图示或公式），一次独立验证（模拟或实验）。画面上的数字都由代码算出。

## 制作细节
- **配色**：最多 3 个用于区分角色的强调色，并且全片一致。同一角色永远用同一颜色，字幕里也一样。
- **可读性**：
  - 浅色字不要压在太阳等高亮区域上，必须加底板或阴影。
  - 1080p 下字幕至少 46 px，单行，不超过 22 个汉字。
- **层次感**：
  - 用视差分层、长影子和轮廓光。
  - 泛光只给自发光元素，再加颗粒和暗角。
  - 避免"扁平矢量 + 渐变底"的廉价感。廉价来自空，不是来自扁平：扁平矢量只要放进一个有密度、有随机变化、一直在动的世界里，就会显得精致。
- **动效**：
  - 一切都要缓动。关键节拍用冲击帧（震动 + 闪白 + 尘土）。
  - 观点之间用倒带、变速或甩镜转场。
  - 不要有超过约 2 秒的静止画面。
- **转场**：落在音乐结构点上（BGM 的重拍、高潮点，可用工具分析电平找出）。安静段落放"顿悟"时刻，片尾前的静音放一句话。
- **声音**：
  - 每个可见事件都配声音：开枪、数字弹出、计数时的滴答、移动时的呼啸。
  - 大的音效出现时压低音乐。
  - 第一秒不能没有声音。
- **结尾**：一句好记的话（成语或金句）加一个开放问题引导评论，只在最后约 1.3 秒淡出。

## 场景化（详见 worldbuilding.md）
- 全屏是一个地方，不是"标题 + 示意图 + 数据卡 + 字幕"的固定版式。
- 每个抽象概念都对应世界里的实物；数据画在世界的物件上（染色的地面、躺着的卷尺、头顶徽章）。
- 角色有名字、有气泡台词、有一次"试错吃亏"。
- 任何一帧至少 4 处与论证无关的环境运动；背景有几十个带随机变化的实例。
- 环境声底跟着场景切换，每个可见变化都有声音。

## 交付前自检
1. 第 0 帧够格当封面吗？遮住字幕，还看得出"在什么地方发生了什么事"吗？
2. 和 `STYLE_LOG.md` 里每一条相比，一眼看上去都不同吗？
3. 所有数字都经过代码验证吗？字幕、图示和模拟三者一致吗？
4. 没有闪帧、黑块吗？亮度曲线没有意外的全黑或全白吗？音频电平正常吗？
5. 成片大小符合目标（默认约 130 MB）、响度已标准化、中间文件已清理吗？

## 画面细节的坑（症状 → 解决办法）
- **俯视角色太小、太抽象**：1080p 下主角约 90 px 以上，轮廓要有辨识度。
- **浅色字压在太阳等高亮区域**：标签后面加半透明底板或描边。
- **切点的闪白让 3 帧以上全白**：峰值不超过 0.6，并快速衰减。
- **地盘染色压在暖色地面上变成橄榄绿**：用 HSL 颜色混合（保留底图明度、只换色相饱和度），代替普通 alpha 叠加。
- **两个角色贴在一起时名字标签互相盖住**：标签按两者距离向外错开，距离越近偏移越大。
- **徽章 / 标签被后画的物体盖住**：绘制顺序固定为 地面 → 染色 → 人群 → 徽章 → 角色 → 标签 → 气泡 → 屏幕空间 UI。
