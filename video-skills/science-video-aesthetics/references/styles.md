# 风格目录（可选视觉 + 声音方案）

这是一份**可选风格菜单**，不是模板。每个视频根据主题自己的意象挑一个方向，可以直接沿用、混合或另起炉灶。

**选择原则**：哪个最贴合主题、最能撑起招牌画面就用哪个，可以与以往的视频重复。

## A2. 已验证的画面笔法（同一场景、21 种画风，都已渲染成片）

同一套几何（灯塔、悬崖、海、帆船、海鸥、云、太阳）交给不同的"画法函数"重画。任一笔法都可以单独作为一个视频的视觉语言，

**组合技巧**：
- 同一场景多画风：场景只写一次几何（多边形 + 随时间变化），每种画风是一个 `paint(t) -> 图像` 函数；可共用"标签图"（每像素属于哪个物体）和"写实参考渲染"（供点彩、像素、字符画、低多边形取色）。
- 配乐跟画风走：全片固定速度和和弦循环，每种画风只换配器，切换时音乐不断；各段按 RMS 统一电平。

## 选择方法
1. 从主题自身的意象出发：主题里的人物、器物、场景、年代、地域是什么？
2. 提 2–3 个候选方向，比较哪个最贴合主题。
3. 只渲染两张主视觉帧（第 0 帧钩子 + 招牌可视化）做 look-dev，不惊艳就换。
